# Product brief

## Working name

My Tracker

## Vision

Turn every new browser tab into a quiet personal control surface where a user can capture a thought, remember a deadline, or understand the next step of a large project without opening another application.

## Target user

The MVP serves one person working on one Chrome profile, especially a developer who:

- Captures bugs, messages, ideas, and short reminders while working.
- Uses AI coding agents to generate large implementation plans.
- Wants those plans visible as goals and tasks rather than buried in chat or Markdown.
- Values privacy and immediate local access over collaboration or cloud sync.

## Problems

1. Small notes and deadlines are lost between chat, editor, browser tabs, and messaging apps.
2. Large AI-generated plans are difficult to scan and keep current when stored only as prose.
3. Full project-management tools add navigation and configuration overhead for personal work.
4. Manually retyping an AI-generated plan into a task manager is wasteful and error-prone.

## Product promise

- Capture in seconds.
- See large work as a small number of visual goals.
- Open a goal to manage phases and tasks with a simple Kanban workflow.
- Import a structured plan generated by an AI instead of retyping it.
- Keep data local and exportable.

## Experience principles

### Local first

Core use never requires an account, network request, remote API, or server.

### Fast enough for every New Tab

The useful UI appears immediately from local state. Background work must not block first interaction.

### Simple outside, structured inside

The home view shows compact notes and goal cards. A goal can contain enough hierarchy for a large software project without exposing enterprise project-management complexity. Resting screens reveal only the current context and its essential action; create, rename, and secondary actions use progressive disclosure through a canonical Phosphor icon and focused modal.

### AI-compatible, not AI-dependent

The runtime MVP contains no AI. The product publishes a small JSON contract and prompt so any capable AI can generate a plan for manual review and import.

### Recoverable by design

Important data is never silently removed. Reminders, overdue tasks, and completed work remain until the user explicitly deletes or archives them. Full backup and restore are first-class.

## MVP capabilities

- Replace Chrome New Tab.
- Quick notes inbox.
- One-time reminders with date and time plus system notification.
- Goal cards with title, last update, and drag reordering.
- Goal hierarchy: phases, tasks, and task checklist items.
- Three task statuses: Todo, In Progress, Done.
- Drag-and-drop plus keyboard-accessible status movement.
- Optional links from notes/reminders to a goal or task.
- JSON Schema-validated AI plan import with preview.
- Lossless JSON backup export and replace-from-backup restore.
- Calm dark visual system with flat surfaces, readable UI type, restrained
  code-native pixel accents, and Goal cards presented as pixel-pin notes.

## Explicitly outside MVP

- Authentication or accounts.
- Cloud sync or multi-device sync.
- Collaboration, sharing, comments, or assignees.
- Runtime AI generation or chat.
- Google Calendar, Todoist, Jira, GitHub, or other integrations.
- Mobile or standalone desktop app.
- Recurring reminders, snooze, habits, calendar views, time tracking, analytics, or gamification.
- User-configurable workflow columns.
- Chrome Web Store publication.

These exclusions are product boundaries, not permanent rejections. Future work must preserve the local-first model and versioned data contract.

## MVP success signals

The MVP is successful when the owner can:

1. Use the extension for one real project for seven consecutive days without returning to a separate task app for that project.
2. Import a non-trivial AI-generated plan without manually recreating its phases and tasks.
3. Close and reopen Chrome without losing data or reminder schedules.
4. Restore a complete exported backup in a clean test profile.
5. Identify the current phase and next task of a goal within ten seconds of opening a new tab.

These are product validation signals, not analytics requirements; the MVP must not add telemetry to measure them.

## Core vocabulary

| Term | Meaning |
| --- | --- |
| Goal | A large personal outcome represented by a compact, original pixel-pin note card. |
| Phase | An ordered stage inside a goal. It groups tasks but is not a Kanban status. |
| Task | A Kanban card inside one phase. Sometimes called “Big Task” in early discussion. |
| Checklist item | A small step inside a task. It is not independently draggable on the board. |
| Quick note | Free-form short text in the inbox. It may be converted or linked later. |
| Reminder | A persistent item with a due date/time that produces a system notification. |
| AI plan | A nested, schema-valid import file designed for human or AI authors. |
| Backup | A lossless normalized export of all app-owned domain data and settings. |

## Primary acceptance journey

```text
Open New Tab
  -> create Goal
  -> add Phase
  -> add Task
  -> move Task from Todo to In Progress
  -> close the tab/browser
  -> reopen New Tab
  -> see the same hierarchy, order, and state
```
